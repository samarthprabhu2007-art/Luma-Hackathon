# Luma Hackathon

Level 1 pairs borrower reminders in Indian languages with a Cashfree sandbox payment flow.

| Start here | What you'll find |
| --- | --- |
| [Team setup](requirements.md) | Install the Sarvam SDK, configure the API key, and run the reminder scripts. |
| [Level 1 PRD](docs/PRD-level1.md) | Demo scope, acceptance criteria, and team responsibilities. |
| [Hackathon brief](docs/About_Hackathon.md) | Event schedule and ground rules. |
| [Sarvam testing UI](testing/README.md) | Run a chat locally or test it from a phone through Cloudflare. |

The reminder integration lives in `sarvam_reminder.py`. The API client setup it shares with the chat scripts lives in `sarvam_client.py`.
