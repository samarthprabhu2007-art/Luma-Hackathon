## 2. Official theme / mission

“150 builders. One day. Agents that move real money.”

Build an AI agent using Sarvam AI's Indian-language models and Cashfree's payment APIs. The concept is that a person expresses a financial need, the agent understands it, takes a payment-related action that moves money, and responds to the person.

The page gives a spoken-language example: someone says what they need in Hindi, Tamil, Kannada, or Bengali, and the agent acts. It also explicitly says possible interaction modalities include voice, chat, documents, or WhatsApp. These are examples/options, not a stated restriction to four languages or a requirement to use voice only.

The agent must be demonstrable live by the evening. The event is framed around real money problems experienced by Indian businesses and their customers.
